## ✦ Overview

**NovelCompanion** is a creative software project by Visella Estesia, designed to support the full lifecycle of writing a novel without turning the creative process into a generic chatbot workflow.

The project separates responsibilities across specialized AI roles so drafting, continuity, editorial review, visual direction, business thinking, marketing, and finance can stay distinct while still working as one studio.

## ✦ Studio concept

| Area | Purpose |
| --- | --- |
| Writing | Draft scenes, chapters, dialogue, and revisions |
| Canon & Editorial | Protect continuity, character logic, timeline, and quality |
| Visual | Covers, concepts, art direction, and presentation |
| Strategy | Product and business decisions |
| Marketing | Content planning, positioning, and distribution |
| Finance | Budget awareness and project-level financial tracking |

## ✦ Repository status

This repository currently contains the Android build source used by the project.

- Default branch: `main`
- Android source package: `NovelCompanion_Vivi_Android.zip`
- CI workflow: `.github/workflows/build-apk-from-zip.yml`
- Debug APK builds are produced through GitHub Actions

The repository structure is still evolving and may be normalized as development moves away from ZIP-based milestone packaging.

## ✦ Design principles

- Preserve story canon and continuity
- Keep creative roles clearly separated
- Prefer deliberate workflows over one giant assistant
- Make model choice and cost visible
- Treat memory, decisions, and project history as first-class data
- Keep the creator in control
