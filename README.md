# NovelCompanion

**NovelCompanion** is Visella Estesia's AI-assisted writing studio project for planning, drafting, canon control, editorial review, visual work, marketing, business, and finance workflows around long-form fiction.

## Repository status

This repository currently acts as the Android build source for the project.

- Default branch: `main`
- Android project source: `NovelCompanion_Vivi_Android.zip`
- CI workflow: `.github/workflows/build-apk-from-zip.yml`
- Debug APKs are produced through GitHub Actions

## Project direction

NovelCompanion is designed around multiple specialized AI workers with separate responsibilities for writing, editorial consistency, visuals, strategy, marketing, and finance.

Development is iterative. Build artifacts and internal experiments may change as the architecture matures.
